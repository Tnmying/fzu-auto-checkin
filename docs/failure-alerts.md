# Python / GitHub Actions 异常提醒

登录失败（包括缺少凭据）、今日状态查询异常（包括 token 被拒绝、HTTP 错误、超时、响应解析异常）、提交失败及定位越界会调用已有的推送渠道，并以非零退出码让 Actions 显示失败。

查询错误不再被统一解释为“没有计划”，也不再在 21:45 后静默。提醒不会断言网络错误就是 token 过期；请按错误阶段检查，并在确认凭证失效后更新 CONFIG_YAML。

自动运行每天（北京时间）最多成功发送一次这类异常提醒。工作流使用 Actions cache 保存送达日期，不包含账号、token 或推送密钥；只有推送 API 确认成功才写入。推送失败会在后续运行重试。缓存不可用或被清理时可能重复通知，因此不是严格的额度保证。学校签到成功通知照常发送。

手动勾选 force 会跳过去重，便于验证修复，每次手动失败都可能占用推送额度。日志和通知仅显示异常类型及 HTTP 状态，不包含可能带凭据的异常正文。Actions 红叉和阶段标题用于排查。

边界：程序必须已经启动、配置能够加载、推送渠道可用且有额度，微信通知才可能送达。依赖安装失败、配置无法解析、GitHub 未触发/延迟、推送服务故障不在本提醒覆盖范围。推送 API 接受请求也不等于手机一定即时收到。当前 Python 版不会自动刷新已有的失效 token。

离线验证：`python -m pytest tests -q`。测试模拟登录、token 拒绝、HTTP 401/403/500、超时、连接异常、坏 JSON、去重及发送失败重试，不调用真实学校接口或推送服务。
